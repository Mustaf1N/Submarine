# HoweMine — обзор сборки на продажу · монтаж, пайплайн, QC

Ролик-обзор Minecraft-сборки **HoweMine**, собранный из двух сырых записей экрана
полностью автоматическим пайплайном: анализ кадров → EDL → посгментный рендер в ffmpeg →
графика из кода → мастеринг звука → QC с доказательствами. Ни одного действия в GUI.

> ## Статус
>
> * **Пайплайн готов и проверен end-to-end.** Все скрипты отработали полный цикл:
>   анализ кадров → EDL → рендер → QC → отчёты. Прогон на синтетических «двойниках»
>   записей (те же разрешения, пропорции и дефекты: панель задач Windows, 4:3,
>   тёмная арена, лаги-замирания, окно OBS) даёт **QC: всё ОК, 0 чёрных кадров,
>   0 неожиданных замираний, −14.3 LUFS, TP −1.53 dBTP, A/V Δ 0.01 с**.
> * **Артефакты в `edit/qc/` и `docs/` помечены баннером «Данные синтетического
>   self-test»** — это доказательства работоспособности пайплайна, а не монтаж
>   реальных записей. После прогона на исходниках они перезаписываются
>   автоматически (`bash run_all.sh`).
> * **Исходные записи (479 МБ и 149 МБ) остались в Google Drive.** В эту среду они
>   не скачались: исходящая сеть ограничена (drive.google.com недоступен), а коннектор
>   Drive отдаёт файлы только до 100 МБ. Поэтому финальный 12-минутный рендер не
>   выполнен — для него нужны сами файлы в `raw/`.
> * Скрипт `tools/build_repo.py` готов создать отдельный приватный репозиторий
>   `howemine-build-review` и залить туда ролик в Releases одной командой.

## Что это

Две записи прохождения сборки HoweMine превращаются в один рекламно-обзорный ролик
**12:00–13:30** (жёсткий коридор 10:00–15:00) с плотным монтажом:

* **источник A** — 23:19, 1920×1080, 60 fps: спавн, торговля, крафт, база, сундуки,
  донат-кейсы, локации, путешествие, лут, стройка;
* **источник B** — 1:22, 1280×960 (4:3), 60 fps: арена и Эндер-дракон.

Обе записи приводятся к одному виду 1920×1080@60 и одному грейду, чтобы картинка
выглядела как из одного ролика.

## Технические характеристики

| Параметр | Значение |
|---|---|
| Разрешение / fps | 1920×1080, 16:9, 60 fps |
| Видео | H.264 **High@4.2**, CRF 19, `keyint=120:min-keyint=60`, `+faststart` |
| Аудио | AAC **256 kbps**, 48 кГц, stereo |
| Громкость | **−14 LUFS** integrated, True Peak **≤ −1.5 dBTP** |
| Длительность | 12:00–13:30 (коридор 10:00–15:00) |
| Кроп источника A | `crop=1822:1025:49:55` → апскейл 1920×1080 (панель задач срезана) |
| Лэйаут источника B | картинка 1440×1080 по центру + размытый затемнённый фон по бокам |
| Грейд | контраст 1.07, насыщенность 1.08, unsharp 0.45; для тёмной арены gamma 1.45 |

## Как воспроизвести

```bash
# 1. исходники (в git не коммитятся — см. .gitignore)
mkdir -p raw
cp "Minecraft 2026.11.23 - 18.27.09.01.mp4" raw/A.mp4
cp "Minecraft 2026.11.26 - 03.19.04.01.mp4" raw/B.mp4

# 2. всё одной командой
bash run_all.sh

# или по шагам
python3 edit/analyze.py        # покадровые фичи 0.2 с → edit/analysis/analysis.json
python3 edit/timeline.py       # EDL, подгонка длительности → edit/timeline.json
python3 edit/render.py --all   # оверлеи + сегменты + конкат + звук + мукс
python3 edit/qc.py             # контактные листы, стыки, blackdetect/freezedetect, LUFS
python3 edit/report.py         # docs/ОТЧЁТ.md, docs/ГЛАВЫ.md, docs/howemine.srt
```

Требования: Python 3.11, `ffmpeg` (с libx264/aac), `numpy`, `pillow`, `scipy`,
`av` (PyAV — используется вместо ffprobe, если его нет в системе).
Скрипты сами находят ffmpeg: `PATH` → `FFMPEG=...` → бинарник из `imageio-ffmpeg`.

Проверка пайплайна **без** исходников:

```bash
python3 tools/make_test_media.py --minutes 0.6   # синтетические двойники записей
python3 edit/timeline.py --time-scale 0.0257 --out work/timeline_test.json
python3 edit/render.py --timeline work/timeline_test.json
python3 edit/qc.py --timeline work/timeline_test.json
```

## Как устроен пайплайн

```
raw/A.mp4 ─┐
           ├─ analyze.py ──> analysis.json   (luma, motion, HSV-маска GUI, чат,
raw/B.mp4 ─┘                                 замирания, чёрные интервалы)
                                 │
                    timeline.py  ▼  (единственный источник правды)
                   timeline.json: {src, in, out, speed, camera, trans_in,
                                   overlays[], sfx[], protected}
                                 │
        ┌────────────────────────┼───────────────────────────┐
        ▼                        ▼                           ▼
   gfx.py + overlays.py     render.py: сегменты         audio.py: музыка+SFX
   (PNG/видео-слои,         (кроп/лэйаут/грейд/спид/    (синтез, ducking,
    пружины, буквы,          камера/переходы/оверлеи,    two-pass loudnorm,
    виньетки)                ffv1+pcm, кэш по хэшу)      точный True Peak)
        └────────────────────────┼───────────────────────────┘
                                 ▼
                       concat -c copy → mux (H.264+AAC) → qc.py → report.py
```

* **EDL — единственный источник правды.** Правка одного таймкода в `timeline.py`
  пересобирает только затронутые сегменты (кэш по хэшу параметров в `work/cache/`).
* **Графика генерируется кодом**: карточки, кинетические титры глав, плашки-выноски
  с линией-указателем и виньеткой объекта, freeze-frame, флеши. Анимации —
  пружинный overshoot, появление по буквам, рост линии, затухание.
* **Камера**: push-in 105–115 % с easing, «дыхательный» дрейф и микро-шейк
  (амплитуда ≤ 0.5 %) через `zoompan` с выражениями по номеру кадра.
* **Переходы**: whip-pan (сдвиг + смешение кадров), zoom-blur, световой флеш;
  ~1 переход на 8–12 с, остальное — прямые склейки на действии.

## Правила монтажа

1. **Режется только брак.** Замирания картинки дольше 0.8 с вырезаются **только там,
   где не открыт GUI** — статичный инвентарь/сундук это контент, он остаётся.
   Порог определяется по HSV-маске серых панелей Minecraft (`gui_score`).
2. **Защищённые участки нельзя трогать.** Окна анимаций кейсов, выдачи награды,
   прокрутки лута помечены `"protected": true`: оптимизатор не меняет их скорость,
   вырезка брака не может зайти внутрь (`subtract(..., protected=...)`), и QC
   проверяет, что `speed == 1.0`.
3. **Длительность подгоняется только за счёт «гибких» сегментов** (ходьба, обзоры):
   целевые 12:30, коридор 10:00–15:00. Защищённые не участвуют.
4. **Темп**: динамика — смена плана каждые 2–4 с, обзоры — 5–8 с, медленная ходьба
   ускоряется ×1.5–2.5; ни одного статичного кадра дольше 7 с.
5. **Хотбар, здоровье и панель действий не обрезаются** ни на одной записи.

## Звук

* **Музыка** — один трек 100 BPM (ля-минор, 16 тактов) на весь ролик, синтезирован
  процедурно: kick/clap/hat, бас, пэд, арп. Секции `sparse → full → breakdown`.
* **SFX** — тоже синтезированы: `whoosh`, `click`, `tick`, `pop`, `low_boom`,
  `riser`, `hit`, `ui_open`. Кладутся по EDL (`sfx[]`), с привязкой к локальному
  времени сегмента.
* **Ducking** — музыка −8 дБ в защищённых окнах (там голос/реакции), плюс просадка
  под карточками и титрами.
* **Мастеринг** — компрессия (crest factor игрового микса 18–22 дБ) → two-pass
  `loudnorm` → точная подгонка по замерам → проверка True Peak с 4× oversampling
  (по BS.1770), затем контроль пика уже после AAC-энкода.

## QC с доказательствами

`python3 edit/qc.py` создаёт:

| Артефакт | Что доказывает |
|---|---|
| `edit/qc/contact_*.jpg` | контактные листы: кадры каждые 30–60 с всего ролика |
| `edit/qc/junctions/*.jpg` | 4 кадра вокруг каждой склейки (−0.3 / стык / +0.3 / +0.6 с) — анимации не обрезаны; приоритет у защищённых участков |
| `edit/qc/qc.json` | машинный результат: blackdetect, freezedetect, LUFS, TP, A/V-синхрон |
| `docs/QC.md` | человекочитаемая сводка |
| `docs/ОТЧЁТ.md` | главы, вырезанное, ускоренное, защищённые окна |

Критерий приёмки: **0 чёрных кадров, 0 неожиданных замираний (намеренные
freeze-frame перечислены отдельно), −14 LUFS, TP ≤ −1.5 dBTP, A/V Δ ≤ 0.15 с.**

## Структура репозитория

```
README.md                  этот файл
brief.md                   исходное ТЗ
run_all.sh                 весь пайплайн одной командой
deliver/                   финальный ролик (или ссылка на Releases)
edit/
  cfglib.py                константы, ffmpeg/ffprobe, шрифты, кэш-ключи
  analyze.py               покадровый анализ → edit/analysis/
  timeline.py              построение EDL → edit/timeline.json
  gfx.py                   процедурная графика (карточки, титры, плашки)
  overlays.py              рендер графики в слои с альфой (ffv1/bgra)
  render.py                сегменты, конкат, звук, мукс
  audio.py                 синтез музыки/SFX, микс, мастеринг
  qc.py                    QC с доказательствами
  report.py                ОТЧЁТ.md, ГЛАВЫ.md, .srt
  timeline.json            EDL (генерируется)
  qc/                      контактные листы и стыки
tools/
  make_test_media.py       генератор синтетических двойников записей
  build_repo.py            сборка отдельного репозитория + Releases
  ffprobe_shim.py          замена ffprobe через PyAV
docs/
  ОТЧЁТ.md, QC.md, ГЛАВЫ.md, howemine.srt
```
